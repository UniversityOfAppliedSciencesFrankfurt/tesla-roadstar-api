# Tesla Roadstar API

An experimental project to explore and develop API modules that mimic
functionalities associated with a Tesla Roadster. The goal is to build a
software representation of vehicle features and the services that could
interact with them.

This is an independent project and is not affiliated with or endorsed by Tesla.
It does not connect to Tesla vehicles or represent an official Tesla API.

## Project status

The repository is at an early stage. It currently contains a .NET 10 project
scaffold; vehicle modules and API functionality are still to be developed.
Potential areas to explore include vehicle status, charging, and controls.

## Getting started

Install the .NET 10 SDK, then build the solution from the repository root:

```bash
dotnet build source/TeslaRoadstarApi.slnx
```
